# Booki - Plateforme de Recherche de Locations

Application web réactive pour rechercher des hébergements et activités à Marseille.

## ✨ Fonctionnalités

- Recherche d'hébergements par localisation
- Filtrage par budget (Économique, Familial, Romantique, Pépites)
- Hébergements populaires avec évaluations
- Activités locales en vedette
- Design 100% réactif (mobile-first)

## 🛠️ Technologie

- HTML5 - Balisage sémantique
- CSS3 - Flexbox réactif
- Font Awesome 6.2.1
- Google Fonts (Raleway)

## 📁 Structure

```
├── index.html
├── css/style.css
└── images/
```

## 🚀 Démarrer

```bash
git clone https://github.com/m-haile/booki-starter-code.git
cd booki-starter-code
```

Ouvrez `index.html` dans votre navigateur, ou démarrez un serveur local :

```bash
python -m http.server 8000
# ou
npx http-server
```

Puis visitez `http://localhost:8000`

## 📱 Responsive

- Mobile (< 768px)
- Tablette (768px - 1200px)
- Bureau (> 1200px)

## ♿ Accessibilité

- HTML sémantique
- Étiquettes ARIA
- Contraste approprié

## 📝 Notes

Ceci est un **projet frontend uniquement** créé pour la formation OpenClassrooms. Les fonctionnalités de réservation nécessitent un backend.
